## ✨ Overview

The **Store Orders Inventory Portal** is a high-end, real-time administrative dashboard designed for tracking, managing, and updating customer orders seamlessly. Built with a bespoke **Obsidian Black & Metallic Gold** luxury aesthetic, it provides live synchronization via Firebase Firestore, intuitive status management, and custom mobile-optimized workflows.

---

## 🚀 Key Features

* **🔒 Secure PIN Authentication**: Fast, secure 4-digit numeric PIN login restricted to authorized store managers.
* **⚡ Real-Time Firebase Sync**: Instant updates across devices as new customer orders arrive.
* **🎨 Dual Theme Support**: Seamless toggle between a **Luxurious Dark (Obsidian & Gold)** theme and a **Warm Light (Cream & Gold)** theme.
* **🖼️ Custom Branding**: Ability to upload and persist your store logo directly into the portal header.
* **📱 Optimized Search**: Fast Order ID lookup featuring an automatic numeric keypad trigger for mobile users.
* **🔄 Advanced Status Management**: Categorize orders across flexible stages:
  * ⏳ `Pending`
  * 💳 `Pending Payment`
  * 🚚 `Pending Delivery`
  * ✅ `Delivery Completed`
  * ❌ `Cancelled` *(with secure deletion permissions)*
* **📊 Dedicated Statistics Dashboard**: Comprehensive page breaking down live metrics and order counts by status.

---

## 🛠️ Technology Stack

* **Frontend**: HTML5, Vanilla JavaScript (ES Modules)
* **Styling**: Tailwind CSS (Custom configured luxury color palettes)
* **Database & Realtime Sync**: Firebase Firestore (v10.8.0)
* **Hosting**: GitHub Pages

## ⚙️ Quick Start / Installation

Because this portal is built as a single-file application powered by client-side Firebase modules, setup is extremely simple:

1. Clone or download this repository to your local machine.
2. Open the `index.html` file in any modern web browser or host it directly via **GitHub Pages**.
